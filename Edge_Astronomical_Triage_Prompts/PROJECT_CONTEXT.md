## Current technical decisions

- Default input: NRD center crop, `3×30×30`, while keeping crop size configurable.
- Split: deterministic stratified 50/20/30 train/validation/test manifest, default seed `20260924`.
- Augmentation: horizontal and vertical flips only for the paper-aligned baseline.
- Model family: same architecture with width tiers Tiny/Medium/Large.
- Model output: a single logit; `p_real = sigmoid(logit)`.
- Execution modes: sequential, fixed concurrency and dynamic concurrency.
- Portfolios: all single, pairwise and three-tier combinations.
- Thresholds and ambiguous zones: fit on validation only, then freeze.
- Compression: logical byte accounting in the minimum viable system.
- Development PC evaluation: controlled software-in-the-loop environment, not Jetson timing.
